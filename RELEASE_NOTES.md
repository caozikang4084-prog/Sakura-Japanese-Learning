# Sakura 1.7.4 / Android 1.7.9

First public open-source release.

## Downloads

- `Sakura Setup 1.7.4.exe` – Windows x64 installer
- `Sakura-Mobile-1.7.9.apk` – Android 7.0+
- `Sakura-Desktop-Assets-1.7.4.zip` – desktop audio and Vosk model
- `Sakura-Mobile-Assets-1.7.9.zip` – Android audio and recognition assets
- `SHA256SUMS-RELEASE.txt` – release file checksums

## Changes

- No account, activation code, or license server is required.
- Windows and Android open directly into the learning interface.
- Nearly 7,000 JLPT N5–N1 vocabulary entries and linked grammar content.
- Built-in audio, local shadowing recognition, quizzes, review, plans,
  check-ins, translation knowledge cards, and course progress management.
- Core learning features work offline. Translation and external courses
  require network access.
- Microphone recordings are used for local recognition only and are not
  stored with learning progress.

## Source-build assets

The source repository excludes large generated media. Download the asset
packs above and follow `docs/ASSETS.md`.

## Notes

JLPT organizers do not publish a complete current vocabulary or grammar
list. Sakura is an independent learning tool and is not an official JLPT
product.
