Sakura Mobile 1.7.9

平台：Android 7.0（API 24）及以上
包名：com.sakura.mobile
版本：1.7.9（versionCode 17009）

首版范围：
- 复用桌面版词汇、语法、练习、翻译、学习计划、打卡、跟读录音界面和统一内容层。
- 学习数据独立保存在手机 WebView 本地存储，不连接电脑，不进行进度同步。
- 网课模块已移除 B站搜索、内嵌浏览器和网页播放器。
- 网课改为用户手动新增课程、填写总课数、完成进度、备注和每日打卡。
- 音频由 WAV 母版批量转换为 128kbps、22.05kHz 单声道 MP3，离线随 APK 打包。
- 手机首页提供首屏快捷入口，词汇详情使用可滚动的底部学习面板。
- 罗马音采用独立的移动端换行、字距和行高规则，避免与日文正文混排。
- 跟读录音优先使用 Android 原生 AudioRecord，减少 WebView 媒体能力差异。
- 已录 WAV 使用内置 Vosk Japanese small 模型离线识别，再进入原有文字匹配与声学分析。
- 首次录音时才请求麦克风权限；权限拒绝后提供重试和系统应用设置入口。
- 学习存档支持 Android 系统保存/打开界面，一键导出和导入 Sakura 兼容 JSON。
- 导入会先检查格式、版本、文件大小和可识别状态，再要求用户明确确认覆盖。
- 一键备份自动写入应用专属 Documents/Sakura/Backups，并保留最近 20 份文件。
- 数据页显示最近备份并支持一键恢复；系统保存器和文件选择器继续用于跨设备副本。
- 系统朗读后备改为 Android TextToSpeech，缺失日语语音时给出明确提示。
- 应用进入后台时停止录音和朗读；识别期间禁止开始下一次录音。
- Mobile UI V4 统一了手机端边距、控件高度、文字层级、安全区和弹窗滚动。
- 学习卡片中的周任务、错题、练习轮次和语法长内容允许自然换行。
- 手机横屏采用紧凑侧边导航并压缩顶栏，保留桌面端正常功能。
- 朗读提示只在 MP3 缺失/失败且 Android TTS 也不可用时出现，不再用 WebView 语音列表误报。
- 单词跟读优先使用假名读音对应的已存在 MP3 作为声学参考。
- 打开跟读面板时会真实初始化 Vosk 模型并检查设备兼容性，模型不可用时只禁用识别评分。
- 学习计划新增阶段任务、间隔复习、自适应阶段测试和未完成任务重排。
- 无需账号或激活码，启动后直接进入学习首页。

已知限制：
- 离线识别使用小型日语模型，识别率会受口音、环境噪声和录音距离影响。
- Vosk 文本匹配度仍不等同于真实发音准确度。
- 桌面与手机使用同一 `nihongo-journey` format 1 JSON 信封，可通过系统文件选择器互相导入。
- 翻译依赖 MyMemory 网络服务；纯离线时翻译不可用。
- 本轮已校验 Native/JNI/APK 结构；仍需在实体 Android 设备上验证麦克风与软硬件组合。
- Windows 的网页收藏课程与 Android 的自定义进度课程使用不同字段；备份会原样保留未知课程字段，但另一平台当前不一定会展示对应课程类型。
- 应用专属 `Documents/Sakura/Backups` 目录无需存储权限，但卸载应用时 Android 可能一并删除；跨设备或卸载前请使用“保存备份副本”。

签名：
- 官方发布包使用项目维护者私有 Keystore 签名。
- 源码不包含签名密钥；自行构建时请使用自己的 Keystore。
- 后续升级需要保持相同包名，并递增 versionCode。
