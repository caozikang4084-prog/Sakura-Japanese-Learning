# Security

Please do not publish credentials, personal learning data, private signing
keys, or authorization-server material in public issues.

If you find a security issue, report it privately to the project maintainer
instead of opening a public issue with exploit details.

Sakura stores learning data locally. The translation feature sends the text
submitted by the user to the configured translation service. Microphone
recordings are used for local recognition and are not uploaded by Sakura.
